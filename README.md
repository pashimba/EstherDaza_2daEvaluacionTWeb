# Esther Daza - Segunda Evaluación Tecnologías Web I

Este proyecto es un portal web hecho en Vue.js 3 que muestra personajes de Star Wars utilizando la API pública de SWAPI (https://swapi.py4e.com/).

## 📦 Tecnologías usadas

- Vue.js 3
- Vite
- Fetch API
- HTML/CSS
- Vue Router
